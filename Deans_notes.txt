Use a virtual Python environment
python3 -m venv myenv

source myenv/bin/activate

Install Python uv manager
curl -LsSf https://astral.sh/uv/install.sh | sh

Reuse our virtual Python environment by uv, deletes original myenv
uv sync --active

In vscode, open a Juypter notebook file and ensure "select kernel"
is using the myenv Python environment.

Use the /home/hf_user/llm_engineering/week1/solutions/day1_with_ollama.ipynb
instead of the OpenAI day 1 notebook which costs money. 
ollama pull llama3.2

Note that the Ollama solution is using the OpenAI calls and not the
new Ollama Python module.

To update vscode using Microsoft repository, do
sudo apt update
sudo apt upgrade

When using vscode to remotely attach to the Docker container image,
the localhost ports can be accessed if the ports are manually or
automatically configured to be forwarded.

In the vscode Juypter notebook when using Gradio web UI, it is
necessary to use .launch(inbrowser=True) to open a web browser to
access the automatically forwarded port.
